# 📊 구글 스프레드시트 라이브 연동 및 양방향 자동화 기획서 (Google Sheets Live Sync)

> **문서 상태:** 차기 로드맵 기획서 (아이디어 확정 및 스펙 정의)  
> **작성일시:** 2026-09-22  
> **핵심 가치:** 엑셀 복붙/업로드 공수 ZERO, 카피캣 원천 차단 기술적 해자(Moat), 내 구글 시트와 실시간 연동되는 양방향 비서 경험

---

## 1. 기획 배경 및 시장 기회

### 1.1 엑셀에서 구글 시트로의 대전환 과도기
- 전통적인 소상공인, 프리랜서, 영업직, 커뮤니티 리더들이 기존 로컬 엑셀 파일 관리의 한계(모바일 확인 불가, 버전 꼬임, 공유 불편)를 느끼고 **구글 스프레드시트로 대거 이동하는 과도기**에 진입함.
- 스마트폰과 PC 어디서나 실시간으로 명단을 작성하고 관리하는 흐름이 대세로 정착 중.

### 1.2 카피캣 방어 및 강력한 락인(Lock-in) 장치
- 단순 텍스트 복붙이나 엑셀 파싱 툴은 누구나 모방할 수 있으나, **개인 구글 계정 OAuth 및 구글 시트 API를 통한 양방향 동기화 엔진**은 일반 카피캣들이 쉽게 흉내 낼 수 없는 강력한 기술적 진입 장벽이 됨.
- 한 번 자신의 핵심 고객 관리 장부(구글 시트)를 센스톡과 연동한 유저는 파일 다운로드-업로드 시대로 절대 되돌아갈 수 없음.

## 2. 유저 인터랙션 및 핵심 UX 3대 혁신

```
┌────────────────────────────────────────────────────────────────────────┐
│               구글 시트 ➔ 센스톡 ➔ 카톡 ➔ 구글 시트 360도 순환 루프             │
└────────────────────────────────────────────────────────────────────────┘

  [1. 평소대로 시트 입력]        [2. 센스톡 자동 감지]        [3. Enter 탕! 탕!]        [4. 시트에 완료 도장]
  스마트폰/PC 구글시트에서  ──▶  센스톡이 대기열로    ──▶  PC 카톡으로           ──▶  구글 시트에 실시간
  고객 추가 or [대기] 체크        알아서 쏙 추출            1:1 맞춤 발송              [발송완료 10:45] 자동 기록!
```

### 2.1 혁신 1: 파일 열기/다운로드/새로고침 ZERO ("시트 수정하면 센스톡이 꿀꺽!")
- **동작**: 유저는 평소 하던 대로 본인 구글 시트(모바일/PC)에서 고객 정보를 추가하거나 메모를 수정.
- **화면 피드백**: 센스톡 상단에 `[🟢 내 구글시트 연결됨: 실시간 동기화]` 상태 표시.
- 유저가 엑셀을 저장하고, 폴더를 열어 드래그 앤 드롭할 필요 없이, **시트에 입력된 내용이 센스톡 수신자 테이블에 실시간/원클릭으로 즉시 반영**.

### 2.2 혁신 2: 스마트 상태 필터링 ("보낼 사람만 쏙 골라오기")
- 수백~수천 명의 전체 고객 장부 중, 발송 대상 컬럼(예: `발송상태`)이 **[대기]**이거나 비어 있는 행만 센스톡이 지능적으로 필터링하여 대기열에 장전.
- 발송이 진행됨에 따라 대기열이 줄어들며 `0건`으로 깔끔하게 비워지는 시각적 성취감 제공.

### 2.3 혁신 3: 양방향 피드백 완료 도장 ("내 시트에 발송 결과 자동 기록!")
- 센스톡에서 [Enter] 타건으로 카카오톡 발송이 성공하면:
  - 센스톡 엔진이 해당 구글 시트의 해당 고객 행의 `발송상태` 열에 **`[발송완료]`** 및 **`발송일시(YY-MM-DD HH:mm)`**를 실시간으로 자동 업데이트(Write-back).
- 유저는 시트만 열어봐도 "아, 오늘 누구누구에게 카톡이 정상 발송되었구나"를 한눈에 파악.

## 3. 기술 연동 아키텍처 및 구현 스펙

### 3.1 Google Sheets API 연동 방식 (2가지 모드 지원)

1. **간편 공개 모드 (Quick Read-Only)**:
   - 구글 시트 "링크가 있는 모든 사용자에게 뷰어 공개" 상태의 URL 입력 시 즉시 파싱.
   - 최초 진입 장벽 없이 3초 만에 시트 명단을 센스톡으로 로드.
2. **풀 파워 양방향 모드 (Full Two-Way Sync / OAuth 2.0)**:
   - 구글 계정 1회 로그인(`https://www.googleapis.com/auth/spreadsheets`).
   - 내 드라이브의 구글 시트 파일 목록을 바로 선택 연동.
   - **실시간 읽기 + 발송 완료 상태 쓰기(Write-back)** 완벽 지원.

### 3.2 컬럼 자동 매핑 엔진
- 구글 시트 1행의 헤더명을 센스톡 치환 변수로 1:1 자동 바인딩:
  - `이름` ➔ `#{이름}`
  - `포인트` ➔ `#{포인트}`
  - `만료일` ➔ `#{만료일}`
  - `상태` ➔ 대기열 필터링 및 완료 도장 기록 컬럼으로 자동 지정.
