# 🤖 센스톡(SensTalk) 2대 핵심 AI 기능 기획서: 발송 사고 방지기 & 톤앤매너 조율사

> **문서 상태:** 정식 로드맵 기획서 (아이디어 확정 및 상세 스펙 정의)  
> **작성 일시:** 2026-09-22  
> **기획 방향:** 억지 챗봇 배제, 1:1 대량 발송 워크플로우에 완벽히 밀착된 **"진짜 실용적인 AI 스마트 비서"** 구축  
> **핵심 2대 기능:**  
> 1. 🛡️ **AI 스마트 발송 사고 방지기 (Pre-flight Audit)** — 1초 만에 치명적 실수 차단  
> 2. ✨ **AI 톤앤매너 조율사 (One-Click Tone Transformer)** — 원클릭 문장 변환

## 1. 기획 배경 및 문제 정의

### 1.1 대량 발송 유저들의 가장 큰 심리적 공포: "발송 사고"
- 수백~수천 명에게 1:1 맞춤 카톡/문자를 보낼 때, 유저가 가장 긴장하는 순간은 **[Enter]를 누르기 직전**임.
- 엑셀 데이터 일부 행에 직함이나 이름이 비어 있어 **"안녕하세요 님!"**으로 나가거나, 한국어 조사가 맞지 않아 **"홍길동은(는)"**처럼 어색하게 나가는 사고는 브랜드 신뢰도를 치명적으로 깎아먹음.
- 광고성 메시지인데 `(광고)` 표기나 `080 무료수신거부` 번호를 빠뜨려 카카오톡 계정이 정지당하거나 과태료 리스크를 겪는 공포가 상존함.

### 1.2 문구 작성 스트레스: "어떻게 써야 답장이 올까?"
- 많은 소상공인과 실무자가 대충 초안을 써놓고도 *"이게 너무 딱딱한가? 너무 가벼운가? 정중하게 쓰려면 어떻게 고쳐야 하지?"*라며 20~30분씩 고민함.
- 과거 시도하다가 중단되었던 '톤앤매너 변환'을 센스톡 캔버스 블록 구조에 최적화하여 재도입.

## 2. [기능 1] AI 스마트 발송 사고 방지기 (Pre-flight Audit)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   AI 사전 감사 엔진 (1초 퀵 스캔)                         │
└────────────────────────────────────────────────────────────────────────┘
  [유저 발송 시도] ──▶ [AI 백그라운드 1초 스캔] ──▶ [결과 피드백]
                          ├─ 1. 변수 구멍 감지        ├─ 🟢 완벽! 발송 진행
                          ├─ 2. 한국어 조사 어색함      └─ ⚠️ 잠재 사고 발견!
                          ├─ 3. 광고/규제 표기 누락          └─ [원클릭 자동교정]
                          └─ 4. 오탈자 / 금칙어
```

### 2.1 4대 핵심 검사 항목

#### ① 변수 구멍(Blank Variable) 감지 및 대리값 추천
- **문제**: 명단 중 특정 고객의 열(예: `직함`, `소속`)이 빈칸(`null`/`""`)인 경우:
  - 잘못된 발송: *"안녕하세요 #{이름} #{직함}님!"* ➔ *"안녕하세요 홍길동 님!"*
- **AI 조치**:
  - *"수신자 중 3명의 #{직함}이 비어 있습니다. 빈칸을 '고객'으로 대체할까요?"* 경고 팝오버 노출 및 원클릭 적용.

#### ② 한국어 조사(은/는, 이/가, 을/를, 과/와) 받침 자동 교정
- **문제**: 한국어는 앞 글자의 받침 유무에 따라 조사가 달라짐:
  - `진욱` + `이(가)` ➔ `진욱이가` (자연스러움)
  - `민수` + `이(가)` ➔ `민수이가` (어색함! ➔ `민수가`가 맞음)
- **AI 조치**:
  - `#{이름}이(가)`, `#{이름}은(는)` 표기를 감지하여, 각 고객 이름의 종성(받침) 유무를 자동 판별해 실시간으로 매끄러운 단일 조사(`진욱이는`, `민수는`)로 자동 치환.

#### ③ 광고성 규제 표기 및 080 수신거부 필수 검증
- **문제**: 정보통신망법상 영리 목적의 광고 메시지는 `(광고)` 표기와 `080 무료수신거부` 번호가 의무 사항임.
- **AI 조치**:
  - 본문에 프로모션, 할인, 이벤트 키워드가 포함되어 있으나 블록의 `isAd`가 꺼져 있거나 080 번호가 누락된 경우 즉각 알림:
  - *"⚠️ 할인/혜택 안내 문구가 감지되었습니다. 광고성 표기 규정 준수를 위해 [광고 표기 및 080 번호 자동 삽입]을 권장합니다."*

#### ④ 스팸 필터링 유발 키워드 사전 경고
- 포털/통신사 스팸 필터에 걸려 전송 실패를 유발하는 고위험 키워드(불법 대출, 도박성 오인 단어 등)를 사전에 걸러내어 도메인/발송자 평판 보호.

### 2.2 UX 흐름
1. 유저가 발송 도크에서 **[Enter] 카톡 연속 발송 버튼**을 누를 때 첫 1회 자동 실행 (설정에서 on/off 가능).
2. 또는 캔버스 상단 액션바의 `[🛡️ AI 발송 점검]` 버튼을 직접 클릭.
3. 이상이 없으면 `🟢 발송 준비 완료 (결함 0건)` 초록 배지가 0.5초간 반짝인 뒤 즉시 발송 모드로 진입.
4. 결함 발견 시 깔끔한 인라인 카드가 열리며 **`[원클릭 일괄 자동 교정]`** 버튼 제공.

## 3. [기능 2] AI 톤앤매너 조율사 (One-Click Tone Transformer)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   캔버스 블록 속 4대 톤앤매너 조율사                      │
└────────────────────────────────────────────────────────────────────────┘
  [내가 쓴 원문 초안]
  "다음 주 월욜에 기기 점검 가니까 집에 꼭 계셔주세요. 부품 갈아야 해요."
                           │
                           ▼ [✨ AI 톤 변환] 클릭!
  ┌────────────────────────────────────────────────────────────────────┐
  │ 👔 정중한 비즈니스 톤 : "고객님, 안녕하십니까. 다가오는 월요일..."    │
  │ 😊 다정·친근 썬드림 톤 : "#{이름}님! 주말 잘 보내셨나요? 월요일에..." │
  │ ⚡ 3줄 핵심 요약 톤   : "• 점검 일시: 9/28(월)\n• 내용: 기기 점검..." │
  │ 🛒 혜택 세일즈 톤     : "놓치면 아쉬운 램프 무상점검 혜택! 월요일..."   │
  └────────────────────────────────────────────────────────────────────┘
                           │
                           ▼ [이 톤으로 적용하기] ➔ 캔버스에 즉시 반영!
```

### 3.1 4대 톤앤매너 프리셋 정의

| 톤앤매너 프리셋 | 주 타겟 / 상황 | 문체 및 특징 |
|---|---|---|
| **👔 정중한 비즈니스** | B2B, 격식 있는 고객, 첫 안내, 병원/기관 | 극존칭, 단정한 문장, 신뢰감 주는 격식체 (~하셨습니까, ~바랍니다) |
| **😊 다정·친근 (썬드림)** | 환우 케어, 단골 고객, 일상 안부, 소통 | 따뜻한 공감, 이모지(과하지 않게 1~2개), 부드러운 대화체 (~해요, ~드려요) |
| **⚡ 3줄 핵심 요약** | 중요 공지, 일정 마감, 바쁜 현대인 대상 | 불필요한 미사여구 제거, 글머리 기호(•) 기반 명확한 3줄 요약 |
| **🛒 혜택 세일즈** | 이벤트, 포인트 소멸 안내, 신제품 런칭 | 행동 촉구(CTA), 혜택 강조, 매력적인 카피라이팅 |

### 3.2 핵심 기술 수칙 (Strict Prompt Engineering)
1. **치환 변수 100% 보존**: 원문에 포함된 `#{이름}`, `#{직함}`, `#{전화번호}` 등 센스톡 변수는 톤 변환 과정에서 절대 지우거나 왜곡하지 않고 원래 위치에 자연스럽게 배치.
2. **글자 수 한도 인식**: 선택된 채널(SMS 90바이트, LMS 2,000바이트 등)에 맞추어 넘치지 않는 최적 길이 유지.
3. **원클릭 비교 뷰(Diff Preview)**: 기존 문구와 변환된 문구를 한눈에 대조하고 `[되돌리기]`도 언제든 가능.

## 4. 기술 아키텍처 및 비용 최적화 전략

```
[센스톡 프론트엔드]
       │
       │ API Request (초안 텍스트, 수신자 변수 목록, 목표 톤)
       ▼
[허브앱 백엔드 / Supabase Edge Functions]
       │
       │ 경량 초고속 모델 호출 (Gemini 1.5 Flash or Claude 3.5 Haiku)
       ▼
[LLM 응답: JSON 규격]
  {
    "issues": [ ... ],       // 발송 사고 결함 리스트
    "transformed_text": "..." // 톤 변환 결과
  }
```

* **비용 및 속도 극대화**:
  - 복잡하고 무거운 거대 모델 대신, 속도가 0.5초 이내이고 토큰 비용이 극히 저렴한 **경량 고속 모델(Gemini Flash급)**을 사용하여 1회 변환당 비용을 1원 미만으로 억제.
  - 규칙 기반(Regex, 사전) 검사는 프론트엔드 JS에서 0초 컷으로 즉시 수행하고, 미묘한 문맥/비문 검사만 LLM에 위임하는 **하이브리드 엔진** 구성.

  - AI 톤 변환 월 3회 맛보기 체험.
* **프로 / 비즈니스 유료 요금제 (핵심 지불 트리거)**:
  - **AI 심층 발송 사고 감사 무제한 잠금 해제**.
  - **AI 톤앤매너 조율사 4대 모드 무제한 이용**.
  - *"발송 사고 한 번 막아주는 것만으로도 월 구독료 6,000원~12,000원은 뽑고도 남는다"*는 강력한 ROI 입증.
